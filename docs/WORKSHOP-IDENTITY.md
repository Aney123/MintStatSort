# Identidad del artículo

Artículo existente: https://steamcommunity.com/sharedfiles/filedetails/?id=3816226363

El ID público identifica el artículo y no es una credencial. El archivo real
About/PublishedFileId.txt se conserva únicamente en el respaldo privado; no se
incluye en el Mod instalable para que un clon no intente apropiarse del artículo.
El instalador conserva los bytes del ID de una instalación existente. El titular
puede recuperar su archivo desde el respaldo privado antes de actualizar Workshop.
Instalar o compilar no publica nada en Steam.
